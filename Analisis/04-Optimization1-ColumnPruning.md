# X8 Optimization #1 — Column Pruning (validated A/B)

**Date:** 2026-09-09 | **Status:** ✅ APPLIED & VALIDATED | **Change:** single block in `populate_exit_trend`

## What changed

Added column pruning at the end of `populate_exit_trend()` — the last strategy hook that runs BEFORE the runtime loop (`custom_exit`, `adjust_trade_position`, grind/rebuy engines). The full dataframe (~500 columns × float32) was being passed to runtime; each `df.iloc[-1]`/`iloc[-2]` call built the entire row (pandas `fast_xs`).

**Fix:** keep only the 117 columns that runtime methods actually read (whitelist generated by static scan of `last_candle["X"]`, `previous_candle["X"]`, `df["X"]`, `.get("X")` across all runtime method ranges), drop the rest:

```python
def populate_exit_trend(self, df, metadata):
    df.loc[:, "exit_long"] = 0
    df.loc[:, "exit_short"] = 0
    _keep_cols = frozenset({ ...117 columns... })
    _drop = [c for c in df.columns if c not in _keep_cols]
    if _drop:
      df = df.drop(columns=_drop)
    return df
```

## Pitfall found (why v1/v2 whitelists were wrong)

A first A/B on 5 pairs PASSED but the 75-pair run threw `KeyError: 'CMF_20_1h'` inside `short_exit_rebuy → exit_profit_target`. Root cause: `exit_profit_target()` (line ~1302, an *auxiliary helper called by exits*) reads `last_candle["CMF_20_1h"]` but lives BEFORE my initial scan range (which started at custom_exit L1848). **Lesson: the whitelist scan must include ALL methods that touch `last_candle`, including helper functions above custom_exit (mark_profit_target, exit_profit_target, _bad_trade_controller_*) — i.e. from ~L1282 up.** Re-ran with the corrected whitelist (117 cols incl. CMF_20_1h/4h) → clean on 75 pairs.
